# Shelld Statistics Public Beta v1.0.1 — один установщик для Windows

## Что получает пользователь
Один файл `Shelld-Statistics-Public-Beta-1.0.1-Setup.exe`, который запускается двойным нажатием на Windows 11 x64. Node.js, npm, CMD и Python **не требуются**. Все основные функции работают офлайн в локальной SQLite-базе.

**MT5:** для автоматического импорта всё ещё нужен **десктопный MetaTrader 5**, установленный и подключённый к торговому счёту. Но Python и пакет `MetaTrader5` пользователю теперь устанавливать не нужно: вспомогательный модуль (собранный PyInstaller) входит в установщик и запускается автоматически. Он не отправляет ордера и передаёт учётные данные в локальный процесс через stdin. MT5-синхронизация, в отличие от ручного журнала, требует работающего терминала и соединения с брокером.

## Как автору получить EXE без установки чего-либо на его ПК
1. Открой GitHub и создай **новый** репозиторий `shelld-statistics-public` (не загружай личный `Personal FTMO` проект).
2. Загрузи **содержимое** этой папки Public Beta в корень репозитория (включая скрытую папку `.github/workflows`). Не добавляй свою базу SQLite, логины, пароль и файлы Backup.
3. Открой **Actions** → **Windows Installer (No Node/Python for users)** → **Run workflow**.
4. Дождись зелёной отметки. Открой выполненный запуск и скачай **Artifact: Shelld-Statistics-Public-Beta-Windows-Setup**.
5. Распакуй artifact и получишь готовый `Shelld-Statistics-Public-Beta-1.0.1-Setup.exe` и контрольную сумму `SHA256SUMS.txt`.
6. **До публикации** установи EXE на чистом Windows-профиле без Node.js, Python и MT5. Проверь создание/редактирование сделки, перезапуск, Export PNG, Backup/Restore, второй аккаунт. Для MT5 повтори проверку на компьютере с терминалом MT5 без Python.
7. Когда всё проверено, создай tag `v1.0.1-beta.1`; GitHub Actions добавит EXE в **GitHub Releases** как prerelease. Ссылку подписчикам давай именно на EXE из Releases, не на «Source code.zip».

**Альтернатива:** автор может собрать на своём Windows ПК через `BUILD_WINDOWS.cmd`, но для СБОРКИ ему нужны Node.js и Python 3.12 x64. Пользователям эти программы не нужны.

## Ограничения и безопасность
- **На этой стадии мы подготовили механизм сборки, но готовый EXE здесь не создан и не проверен на чистой Windows.** Выпуск подписчикам допускается только после зелёного GitHub Actions, проверки установщика и работы Backup.
- Установщик **не подписан сертификатом**. Windows SmartScreen может предупредить. Не советуй людям бездумно игнорировать предупреждения: публикуй SHA256 и ссылку на исходный код.
- Личные торговые данные и MT5 пароли никогда не должны входить в публичный репозиторий или образ установщика. Windows может сохранять выбранный пользователем пароль зашифрованно только на его компьютере; он не копируется в общий ZIP.
- Автоматическое обновление не реализовано. Новые версии распространяются новым установщиком, а SQLite-база сохраняется в `%APPDATA%\Shelld Statistics Public Beta`.
- Для мониторинга безопасности выпуска лучше использовать подписанный EXE, зависимость Electron с актуальными security-patches, документацию приватности и репозиторий для сообщений об ошибках.
