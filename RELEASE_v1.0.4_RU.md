# v1.0.4 — Public Beta (Windows 11 x64)

Сборка из Personal Edition v0.8.16, без приватного FTMO-профиля и без доступа к приватной SQLite.

- Notion ZIP → CSV и связанные скриншоты по номерам сделок / страницам Markdown.
- Ручное сопоставление скриншотов, когда Notion не дал точной связи.
- Дубли сделок и изображений при повторном импорте не создаются.
- GER40: синий цвет **только плашки актива** (темная и светлая темы).
- Отдельная от Personal версия с чистым профилем и appId `com.shelld.statistics.publicbeta`.

Релиз публикуется как prerelease после сборки и автоматических тестов GitHub Actions.
