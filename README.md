# Shelld Statistics — Public Beta v1.0.4

**Бесплатный локальный торговый журнал для Windows 11 x64.**

Текущая публичная версия основана на личной редакции v0.8.16, но **не содержит** FTMO-логина, персональных путей, настроек брокера или торговой истории. Устанавливается отдельно от личной редакции — другая папка приложения и собственная SQLite.

## Возможности
- Trading Journal, Dashboard, Advanced Analytics, учёт нескольких счетов, группы фаз.
- Backtest со сделками и встроенным анализом.
- **Импорт полного ZIP Notion**: CSV, страницы Markdown, PNG/JPG/WEBP и привязка скриншотов к сделкам по Number/Notion ID; при неоднозначности доступна ручная проверка.
- Не требует точного времени закрытия, неизвестные поля можно заполнить позже.
- MT5 Connect, локальные резервные копии, Export Studio, теги и заметки.
- Синие плашки **GER40** (остальные цвета интерфейса сохранены).

## Установка
1. Откройте [GitHub Releases](https://github.com/Shelld0/shelld-statistics-public/releases).
2. Скачайте `Shelld-Statistics-Public-Beta-1.0.4-Setup.exe`, если релиз уже успешно собран и опубликован.
3. Установите и запустите. Node.js и Python конечному пользователю не нужны; терминал MT5 требуется только для автоматической синхронизации.

Для разработчиков: `BUILD_WINDOWS.cmd` запускает установку зависимостей, тесты и сборку Windows-инсталлятора. Сам исходный ZIP — **не** EXE.

## Приватность и ограничения
Все записи локальны, отправка торговых счетов на сервер не реализована. Публичная SQLite и папка данных отделены от Personal Edition. Приложение не подписано сертификатом; при установке Windows может показать предупреждение. Это **бета-версия**: сначала протестируйте на чистом ПК, делайте резервные копии. Действующие счета нельзя бездумно подключать с непроверенной сборкой.
