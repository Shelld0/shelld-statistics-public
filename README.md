# Shelld Statistics Public Beta v1.0.1

**Бесплатный локальный торговый журнал для Windows 11 (x64).** Данные хранятся в SQLite на компьютере. Приложение не требует регистрации, облачного аккаунта или MT5 для ручного ввода сделок.

## Обычным пользователям
**Скачайте `Shelld-Statistics-Public-Beta-1.0.1-Setup.exe` из раздела GitHub Releases** после того, как автор опубликует релиз. Запустите установщик и следуйте мастеру. **Не требуется устанавливать Node.js или запускать команды.**

После запуска выберите **Начать без MT5** для ручного ведения журнала или **Настроить MT5** для автоматического импорта с установленного терминала. Инструкция: `PUBLIC_INSTALL_RU.md`.

> Внимание: в этом исходном ZIP готового `.exe` нет. Для создания настоящего установщика автор должен сначала выполнить сборку на Windows или GitHub Actions. Не давайте подписчикам исходники как будто это готовый установщик.

## Возможности
- Trading Journal с Equity Curve, ручными сделками, фотографиями, заметками, тегами и фильтрами.
- Локальное подключение MetaTrader 5 через установленный терминал; встроенный MT5-модуль поставляется внутри EXE, Python от пользователя не требуется. Импорт только для чтения.
- Множество торговых счетов с раздельной статистикой и журналами.
- Advanced Analytics: Long / Short, серии просадок, сравнение торговых моделей, активы и периоды.
- Недельные Trading Plans, Backtests, галерея скриншотов, редактор разметки, вставка Ctrl+V.
- Export Studio: красивые Telegram / Square PNG-карточки без раскрытия логина и сервера.
- Автоматические локальные резервные копии SQLite и ручное восстановление.

## Для автора: как выпустить Windows EXE
См. `PUBLISH_PUBLIC_RU.md` и `.github/workflows/windows-release.yml`. Для собственной локальной сборки на Windows 11 установите Node.js LTS и запустите двойным кликом `BUILD_WINDOWS.cmd`.

**Приватность:** публичная сборка не содержит профилей FTMO, логинов, паролей или пользовательских путей. У неё отдельная папка `%APPDATA%\Shelld Statistics Public Beta` и собственная пустая SQLite-база. Приложение не копирует данные из личной редакции.

**Публикация:** это Beta, не прошедшая полный сторонний аудит безопасности, стресс-тестирование и проверку на нескольких чистых Windows-компьютерах. Установщик по умолчанию не подписан — Windows SmartScreen может показать предупреждение. Не советуйте людям обходить системную защиту без проверки происхождения файла.

## Самостоятельный публичный установщик

Один Windows EXE включает Electron, SQLite и собранный MT5 Python bridge. Пользователям **не нужны Node.js, npm или Python**. Для автоимпорта всё ещё нужен десктопный терминал MetaTrader 5. Инструкция для автора и чек-лист в `ONE_CLICK_RELEASE_RU.md`. В исходном ZIP EXE **не лежит** — его собирает GitHub Actions на Windows.
