# Как опубликовать Shelld Statistics Public Beta для всех

## Цель: один EXE для обычного пользователя
Обычным трейдерам **НЕ НУЖНЫ Node.js и Python**. Для автоматического импорта им потребуется установленный десктопный терминал MT5. В GitHub Releases они скачивают только готовый `Shelld-Statistics-Public-Beta-1.0.1-Setup.exe` и устанавливают его обычным двойным кликом.

### Способ А. GitHub Actions (рекомендуется)
1. Создайте **новый публичный репозиторий** GitHub, например `shelld-statistics-public`.
2. Добавьте **только содержимое этой папки Public Beta**. Личные исходники `Personal FTMO` и ZIP с личным логином туда никогда не загружайте.
3. Разрешите GitHub Actions с доступом на запись к Releases (Settings → Actions → General → Workflow permissions: Read and write permissions, если требуется).
4. Зафиксируйте исходники на ветке `main`.
5. Запустите `Windows Installer` во вкладке **Actions** через **Run workflow** для теста. После успешной сборки в разделе Artifacts появится Windows-установщик.
6. Для публичного GitHub Release создайте git-тег `v1.0.1-beta.1` и отправьте его в репозиторий. Workflow соберёт EXE на Windows, запустит тесты, приложит установщик к Release.
7. Скопируйте ссылку на страницу **Releases** в Telegram/YouTube. Посетителям достаточно скачать один `.exe` из последнего релиза.

Если сборка падает, проверьте лог GitHub Actions. Исходный ZIP не является готовым установщиком.

### Способ Б. Сборка на собственном Windows 11
1. Установите Node.js LTS с официального сайта.
2. Установите Python **3.12 x64 только на компьютер СБОРЩИКА**, если собираете без GitHub Actions. Пользователям Python не нужен.
3. Распакуйте эту папку.
4. Дважды нажмите `BUILD_WINDOWS.cmd`; после проверки и сборки EXE появится в `release/`.
5. Проверьте EXE на другом Windows-профиле, затем приложите его к GitHub Release вручную.

### Перед публикацией Beta — обязательная проверка
- На чистой Windows 11: установка, запуск **без MT5 и Python**, ввод/редактирование сделки, Backtest, Export PNG, перезапуск и сохранение базы.
- Запуск Auto Backup и успешное восстановление тестовой базы.
- Два аккаунта: операции не смешивают сделки разных профилей.
- Опциональное подключение другого брокера к MT5 и тест закрытия позиции.
- Логи и скриншоты не содержат личных данных автора. В этом ZIP нет исходных данных профиля FTMO, но **проверяйте перед каждым релизом**.
- Установщик сейчас **не подписан** цифровым сертификатом. Для массового распространения желательно подписать его и добавить страницу с политикой приватности/контактами разработчика.
- Публикуйте как **Beta**, не как полностью проверенное финансовое ПО.

### Приватность
Приложение хранит базу локально в `%APPDATA%\Shelld Statistics Public Beta`, отдельно от личной версии. Не загружайте в публичный репозиторий свои SQLite-файлы, Backup, логины и торговые пароли.


Обновлённое руководство для v1.0.1 (встроенный MT5-модуль и контрольный список): `ONE_CLICK_RELEASE_RU.md`.
