# Shelld Statistics v0.8.6 — Скриншоты и Backup

## Перетаскивание скриншотов
Открой сделку (Журнал → Сделка → Скриншоты или Результат), строку бектеста (Анализ / Фото) либо актив недельного плана. Удерживай изображение мышью и перетаскивай на нужную позицию. Перестановка записывается в SQLite; после перезапуска порядок сохранится. Новые изображения добавляются в конец.

## Редактор изображений
Наведи на миниатюру и нажми **✎**. Выбери стрелку, карандаш, линию, прямоугольник или текст. Для текста сначала введи надпись, затем щёлкни на нужное место изображения. Можно выбрать цвет и толщину, отменить последнее действие или очистить только новые пометки. Нажми **«Сохранить копию»**. Оригинальное изображение не изменяется: в галерее появляется дополнительный PNG в исходном разрешении. Из-за ограничения 16 МБ на изображение очень крупные размеченные снимки могут потребовать уменьшения размера до вставки.

## Автоматическое резервное копирование
1. Открой **Backup** в верхнем меню.
2. По умолчанию автоматические копии включены. Они создаются при запуске приложения, если за текущий день снимка ещё нет. Проверка повторяется каждый час, пока программа работает.
3. Настрой, сколько копий хранить: **7**, **14** (по умолчанию) либо **30**.
4. Нажми **«Открыть папку»**, чтобы увидеть локальные копии. Копии содержат SQLite с изображениями и торговыми данными, поэтому учитывай свободное место на диске.
5. **«Сделать копию»** создаёт отдельный снимок сейчас. **«Экспорт SQLite»** предлагает выбрать папку. **«Восстановить»** заменяет текущую базу из выбранного файла: прежде приложение создаёт дополнительную защитную копию.

**Важно:** копии создаются только когда Shelld Statistics открыт. Отдельно сохрани важную копию на внешний диск. Пароль MT5, защищённый Windows, не входит в SQLite-бэкап.

## Безопасность личной версии
Этот ZIP содержит локальные пути и личную настройку счёта FTMO. Не распространяй его публично. Для публичной версии нужно удалить пресет и предусмотреть первоначальную настройку.

## Установка и сборка на Windows 11
В новой папке с package.json:

```bat
npm install
npm test
npm start
```

После проверки:

```bat
npm run dist
```

Установщик собирается в папке `release`. Это исходный проект, не готовый EXE.
