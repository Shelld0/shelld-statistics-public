# Shelld Statistics v0.8.4 — «Результат» в сделках и Backtest

## Торговый журнал

1. Открой Trading Journal и выбери сделку → **Редактировать**.
2. Под заметками находится отдельный раздел **«Результат»**.
3. Скопируй изображение в TradingView, в «Ножницах» Windows или другом редакторе (**Ctrl+C**), наведи курсор на кнопку добавления в разделе «Результат» и нажми **Ctrl+V**.
4. Можно также нажать «Добавить скриншот» и выбрать несколько файлов или перетащить их в галерею.
5. Клик по миниатюре открывает оригинал; кнопка **×** удаляет только этот скриншот.

Для **новой** сделки изображения сначала остаются в памяти формы и сохраняются вместе со сделкой после «Сохранить сделку». Для уже созданной сделки изображения записываются сразу. В «Подробнее» альбом также доступен.

## Backtest

Открой Backtest → нужный проект → в строке сделки нажми **Анализ / Фото**. Внизу окна находится отдельный раздел **«Результат»**: наведи курсор на эту галерею и нажми Ctrl+V. Если нужно вставить в таймфреймы, наведи курсор на карточку с нужным ТФ или на «Добавить скриншот» и выбери таймфрейм.

## Отличия от основной галереи

- Старые скриншоты с таймфреймами 1W / 1D / 4H и другие остаются в своих галереях.
- Новый раздел «Результат» не требует выбора таймфрейма и поддерживает несколько изображений на одну сделку.
- Количество изображений в коде не ограничено; ограничение на файл — **16 МБ**. Фактическая вместимость зависит от доступной памяти и размера базы.
- Исходные PNG, JPG, WEBP сохраняются без перекодирования в SQLite. Они входят в резервную копию базы.
- Обычная вставка **текста** через Ctrl+V в заметки работает как раньше.
- В открытом окне выбора таймфрейма Ctrl+V работает с выбранным ТФ. В обычные заметки текст вставляется как раньше. Если курсор не над галереей, изображение не отправляется автоматически в «Результат».

## Обновление

Сделай **Backup** базы перед первым запуском новой версии. Миграция добавляет две таблицы (`trade_result_images`, `backtest_result_images`), не удаляя предыдущие изображения, сделки, аккаунты и настройки MT5.

```cmd
npm install
npm test
npm start
```

После проверки:

```cmd
npm run dist
```

Windows-инсталлятор собирается на компьютере пользователя; готовый EXE не входит в ZIP.
