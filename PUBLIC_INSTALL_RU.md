# Как пользоваться Shelld Statistics — инструкция для пользователей

## 1. Скачивание и установка
1. Откройте официальную страницу автора на GitHub → **Releases** (ссылку публикует автор канала).
2. Скачайте файл **`Shelld-Statistics-Public-Beta-1.0.1-Setup.exe`**, а не «Source code.zip».
3. Запустите установщик, выберите папку, завершите установку. Node.js, npm и команды CMD **не нужны**.
4. Если Windows показывает сообщение SmartScreen, проверьте, что файл получен из официального релиза. Эта тестовая версия может быть без цифровой подписи.

## 2. Первый запуск
Выберите **«Начать без MT5»**, если хотите вести журнал вручную. Приложение полностью работает офлайн, данные никуда не отправляются. Первый профиль называется **«Мой счёт»** — его можно переименовать или добавить другой кнопкой `+` вверху.

Для автоматического импорта выберите **«Настроить MT5»**. Это дополнительная функция; вы сможете вернуться к ней позже через кнопку MT5 Connect.

## 3. Добавление сделки и анализ
- Перейдите во вкладку **Trading Journal** → **Add Trade**. Заполните даты, актив, направление LONG/SHORT, результат, проценты, R и заметки. Вручную введённые данные сохраняются в SQLite.
- Откройте сделку → **Анализ**: добавьте текст, теги, скриншоты любых таймфреймов. Можно скопировать скриншот и вставить его через **Ctrl+V**, наведя курсор на нужный блок.
- **Equity Curve** обновляется по закрытым сделкам. Открытые позиции не считаются реализованной прибылью.
- Вкладка **Analytics** показывает сравнение Long/Short, серии просадок и торговые модели. Значение R не считается известным автоматически, если нет данных об исходном риске.

## 4. Backtest / Trading Plans
- **Backtest** → создать тест → добавить сделки в таблицу, даты и результаты. Раздел «Анализ / Фото» поддерживает заметки, скриншоты и Ctrl+V.
- **Trading Plans** → создать недельный план → открыть актив и прикрепить анализ и скриншоты.
- Функция исторического FX Replay **пока не входит** в эту Beta-версию.

## 5. Подключение MT5 (по желанию)
Подходит для Windows 11 (64-bit) с **установленным настольным терминалом MetaTrader 5**, в который пользователь уже вошёл. Приложение не может получать MT5-сделки напрямую по логину без локального терминала.

1. Установите **настольный терминал MetaTrader 5** от вашего брокера и войдите в счёт. **Python устанавливать не нужно** — в публичном установщике Shelld Statistics уже есть встроенный модуль MT5.
2. В MT5 Connect укажите **свой** логин, сервер брокера и пароль. Пароль можно по желанию хранить с защитой Windows; передавать его кому-либо не нужно.
3. Поле Python **оставьте пустым** (используется встроенный компонент). Если MT5 не находится автоматически, укажите путь к `terminal64.exe`.
4. Укажите реальную базу капитала в валюте своего счёта, чтобы видеть результат в процентах. Без базы программа не должна придумывать проценты.
5. Нажмите **Подключить MT5** → **Синхронизировать**. Автообновление каждые 60 секунд работает, пока приложение и терминал запущены.

**Важно:** импорт работает только на чтение. Редактирование вручную и статус BE можно защищать от последующей синхронизации. Достоверный R по старой истории требует известного первоначального риска.

## 6. Скриншоты и экспорт в Telegram
- Копируйте график в буфер обмена → наведите на нужную галерею → Ctrl+V.
- В редакторе изображений можно нарисовать стрелки/текст и сохранить отдельную копию.
- В **Export Studio** выберите период или сделку, формат Telegram/Square, шаблон и сохраните PNG. Проверяйте, нет ли чувствительных сведений на добавленных скриншотах.

## 7. Резервные копии и перенос на другой ПК
- Кнопка **Backup** → настроить автоматическое ежедневное создание резервных копий (по умолчанию включено).
- Перед переустановкой/сменой ПК выберите **Экспорт SQLite** и сохраните файл отдельно, например на флешке.
- На другом ПК: Backup → **Восстановить** → выбрать свой SQLite-файл. Перед восстановлением сохраняйте текущую базу — операция заменяет её содержимое.
- Локальные данные этой Beta: `%APPDATA%\Shelld Statistics Public Beta\data\shelld-statistics.sqlite`.
- Шифрованный пароль MT5 в копию SQLite не входит: на другом компьютере его придётся ввести заново.

## 8. Помощь и безопасность
Если программа не работает: укажите версию, Windows, текст ошибки и шаги воспроизведения автору релиза. Никогда не публикуйте логин и пароль MT5, исходную базу со своими сделками или скриншоты с номером счёта.
